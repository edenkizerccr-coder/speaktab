# Free SpeakTab practice scores

These 16 short original exercises are ready to **read as supplied**, and each also has a separate project you can **edit in SpeakTab**. All three matching files contain the same sample music. You can choose either route; editing is optional. They are practice pieces, rather than famous classical works or recordings.

## Read a sample without editing

1. Extract the complete Windows ZIP. In the SpeakTab reader press **Ctrl+Shift+F**, then **Try included practice samples**, and choose a `.musicxml` file in `Samples`. **Ctrl+O** can open that same file directly.
2. **Ctrl+T** chooses a supplied part. **Ctrl+2** focuses the music. Left/Right follows musical time; Up/Down inspects simultaneous notes or supplied lyric rows. **F3** opens the full description.
3. **Alt+Shift+L** gives the full supplied lyrics at the selected position. **Ctrl+P** plays the practice preview; **Ctrl+Shift+P** stops it. Vocal preview is wordless.

The sample is readable immediately. You do not need to open the composer, change notes, or use Apply.

## Change a sample in the composer

1. Press **Ctrl+Shift+N** to open the composer. Choose **Open project**, browse to `Samples`, and open the matching `.speaktabscore` file.
2. Use **Save project as** to keep your own copy. Select an applied event on Score to edit it. **Ctrl+E** enters more notes, with optional lyrics; **Ctrl+L** edits words at the selected applied note. Part settings changes a part; Measure tools changes measures.
3. Read the proposed changes, then use **Apply reviewed changes**. Undo can restore an applied change. **Save project** keeps your composition and unfinished entry. **Export MusicXML** makes a separate score from applied music for reading or sharing.

Open project edits compositions made in SpeakTab. It does not turn downloaded MusicXML, MuseScore or PDF scores into editable composer projects. A MusicXML export from SpeakTab can also reopen for composing when its embedded project still agrees with the musical score; the matching project file is the clearest starting point.

## What the files demonstrate

Solo voice has one unaccompanied singer. SATB and barbershop each have four separately named parts; they do not create harmony automatically. Each singer can have independent notes and lyrics. The voice-and-piano example includes two verses.

Violin bow, finger and string markings are written information. Harp pedal diagrams do not retune entered notes or certify that a passage is playable. Written techniques do not synthesize a performance. High-G ukulele has a re-entrant tuning: string 4 is higher than string 3. Choose explicit high-G or low-G tuning before entering frets.

PDFs were typeset from the sample MusicXML with MuseScore. They provide visual references and optional recognition experiments. Prefer MusicXML to read the supplied notes and rhythm directly. PDF recognition may misread or omit music; compare a conversion with the XML or project. Printed engraving is not supplied by the SpeakTab composer itself.

The full manual's final chapter and **Try the free original practice scores** in Guided tutorials explain both reading and editing. All examples are optional; your own music can be used instead. The accompanying **LICENSE.txt** applies only to these original exercises. The app and its bundled libraries retain their own licences. File hashes are in **Samples.SHA256.csv**.

Viola, cello, drum-kit and timpani examples demonstrate their dedicated composer types. Viola starts in alto clef, cello and timpani in bass; unpitched sounds use percussion clef. The full instrument comparison is in the manual and Source guide.
