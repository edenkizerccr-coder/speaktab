# SpeakTab

Android 0.5.9 opens Library with **Control+H then Control+Y** outside text fields. In Reading, **Control+Z then Control+E** gives full details for the selected beat. **Control+R** returns to the music. Tuning and capo apply to fretted parts. The Windows and Android Word manuals have shorter introductions.

Read, hear, practise and compose music.

## SpeakTab Windows 1.0.28 and Android 0.5.9

Windows 1.0.28 teaches New score in the first composing instructions. Press Ctrl+Shift+N, or Tab to New score in Composer and press Space. Ctrl+Enter previews typed entry. After reviewing it, Tab to Apply reviewed changes and press Space or Enter. Ctrl+Shift+Enter applies directly. Checked practice uses its own score and reports what it found, including a proposal waiting to be applied. Piano has its own composing reference, with examples for its notes, rhythms and staves. Review changes starts with the actual proposed music. The lesson accepts lowercase and uppercase pitch letters and checks the resulting notes, timing and written marking. Ctrl+Shift+0 clears the loop. Use the zero above the letters.

Both apps accept several ways to write the same music. Try measure 1 beat 1 C4 quarter note then E4 quarter note, or m1 b1 C4 qn then E4 qn. The manuals show both forms and the same notes on separate lines with explicit positions. Checked practice looks for the resulting music. The Windows marking exercise uses D4 as its second note. In either app, enter crescendo from beat 1 to beat 2 or get louder from beat 1 to beat 2 in the description box to add the expression. Windows tutorial navigation stays responsive while local narration stops.

Android 0.5.9 adds a keyboard action layer outside text fields. Press Control+H, release it, then press the second Control chord. Control+H then Control+N starts a new score from Library, Reading or Composer. Control+H then Control+L opens Learn by doing. On a lesson step, Control+H then Control+O opens the task, Control+H then Control+C checks or continues, and Control+H then Control+Q pauses. Press Control+H twice to list available buttons. Control+K still opens keyboard help. The Reading lesson practises Control+Z then Control+B for the beginning and Control+Z then Control+T for the end. AI Teacher on Android now listens throughout the conversation. Control+O connects on the AI Teacher screen, and the teacher answers when you finish speaking. Speak to interrupt a reply. Control+F pauses the microphone, Control+S resumes it and Control+X ends the conversation. Physical Android keyboard, microphone and live audio still need a device check.

## Reading and practice

Supported score formats include MusicXML, MuseScore, Guitar Pro and textual music. PDF recognition and repair remain experimental and require musical review. Navigate supplied beats, measures, parts, lyrics, chords and markings; use supported practice playback, loops and saved reminders. Vocal parts present note names and octaves without guitar fingering labels. Missing lyric text is not invented. Existing Windows shortcuts and Android Control commands are preserved.

## Composition

Precise selectors and documented local phrases work without an AI account or interpretation charge. Enter notes, simultaneous chords, independent staff/voice rhythms, rests, lyrics, directions and all standard point dynamics. Numeric lengths such as 1.5 beats work for piano and guitar. The local catalog includes 23 guitar shapes and 14 explicit-root piano chord qualities. Enter natural/artificial harmonics with explicit base and touching fret, or adjacent hammer-on, pull-off and slide notes. Review before Apply. Save an editable project and export applied MusicXML. Projects are separate from arbitrary imported scores.

Windows supports Piano, Guitar, Bass, Ukulele, Voice, Violin, Viola, Cello, Harp, Percussion and Timpani. Android also supports those composing instrument types, including named percussion and pitched timpani. Both apps offer supported passage expressions; Android adds reviewed measure tools, slight/wide vibrato playback and real Guitar Pro companion export with a MusicXML master. Read the current manuals for exact forms and limits.

Optional ChatGPT interpretation requires a deliberately selected connection/model. Windows F4 loads/connects models, F5 focuses a pending composer answer and F6 reads its reply. Android uses named controls through F3 and Enter. Questions, replies and unfinished answers are retained; model proposals still need review and Apply. Local entry errors do not trigger automatic online interpretation. Provider features may have separate charges.

## Building and verification

Use the included Build instructions and checks. Public packages preserve runtime and licence material. Do not include personal scores, settings, tokens, signing keys or private diagnostics. Software checks do not replace hands-on device, screen-reader and physical-audio assessment. See Release Notes and the package manifests for the current build and checks.
