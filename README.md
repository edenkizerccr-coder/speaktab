# SpeakTab

SpeakTab is an accessible Windows tab and score reader for keyboard, screen-reader and Braille users. Read supported music, choose a part, hear local previews, slow down, loop passages and keep practice notes. Version 10.14.74 also offers **beta note entry** for composing piano, six-string guitar, vocal parts and their combinations.

## Read and practise

Ctrl+O opens music; F2 finds supported sources; Ctrl+T chooses a supplied MusicXML or MuseScore part. Ctrl+2 focuses the score. Left/Right move through musical time, Up/Down inspect simultaneous notes, strings or lyrics, and F3 opens full details. Ctrl+Shift+I opens supplied score information. Staff numbers identify written staves and do not imply hand assignments in imported music.

Ctrl+P plays; Ctrl+Shift+P stops. Practice offers loops, bookmarks, personal notes and independent practice drums. Ctrl+Shift+9 sets a measure loop; Ctrl+Shift+0 clears it. Ctrl+S saves a reader arrangement and a new loop. File > My readings resumes saved work. Companion chord/lyric sheets remain separate written references. Text, Markdown, HTML and textual BRF exports retain supported reading information; BRF is prose Braille, not music-braille transcription.

## Write music with beta note entry

Choose File > New score or the New score button. The composer opens on Enter music; Ctrl+Shift+Tab from its description box selects Score and its Score settings. **Choose notes and rhythm / Ctrl+E** provides note, accidental, octave, beat, staff, voice, duration and guitar string/fret selectors.

Full phrases and short entry both work. For example, `m2 b1 RH C4 hn` means measure 2, beat 1, right hand, C4 half note. `wn`, `hn`, `qn`, `en` and `sn` mean whole, half, quarter, eighth and sixteenth; lowercase `b` means beat and uppercase `B1` remains a pitch. A named measure continues until another measure is named within the description. Plus joins simultaneous pitches.

Ctrl+Enter previews. Hear proposed score auditions it. Ctrl+Shift+Enter explicitly applies reviewed changes. Notes, rests, chords, independent piano staves/voices, lyric verses, arranging, supported expression and guitar patterns can be revised with Undo/Redo. Save project retains an editable .speaktabscore; Export MusicXML writes all applied parts. Keep both files.

**Note entry is beta.** Review the actual proposal and exported music. The composer does not edit arbitrary imported scores, engrave pages, author percussion or implement advanced guitar techniques. Vocal playback is wordless. Written repeats export while composing audition plays its selected range once. Expression and strum playback are approximations.

## Learn and get help

Guided tutorials on the composer toolbar opens its eight-lesson learning path. Help > Guided tutorials or Ctrl+Shift+H opens all **29 local lessons**, including worked piano/guitar/vocal examples and reader features. The reference window stays open while you practise. Optional tutorial read-aloud uses local Windows voice.

The full 80-page manual, Quick Start, testing instructions, podcast overview, text/HTML versions, keyboard reference and native help are current for 74. Superseded version supplements are removed from the active guide set. F1 gives help; Ctrl+Alt+P finds commands. The main reader layout and its focus-specific arrow controls remain.

## Optional connections and accuracy

F4 connects written ChatGPT, F5 focuses a question, Enter sends once and F6 reads the answer. Composer interpretation proposes edits for review. Ctrl+Alt+L toggles the separate free reader-command microphone. F8 explicitly starts the configured live teacher and F9 stops it. F12 silences enabled app speech without stopping music or microphones. Connected services may incur charges.

PDF/OCR and AI recovery require source comparison. Explicit provisional copies retain warnings and reported gaps. Suitable structured sources usually provide more detail; supplied strings, tuning, clefs, lyrics and timing remain source-dependent. The main gate and seven affected software checks passed for 74, with authored MusicXML schema checks and visual review of changed documentation. The broad historical/corpus suite was not rerun. Physical screen-reader/Braille/audio/microphone acceptance and live-model musical quality remain hands-on checks.
