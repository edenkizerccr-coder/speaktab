# SpeakTab

SpeakTab is a Windows music reader and practice companion for blind and low-vision musicians. Explore supported guitar and piano music with a keyboard, screen reader or free voice commands. Read notes and chords, hear a practice preview, slow down and loop a passage, and save places and practice reminders.

## Start and navigate

Extract the complete application ZIP with its runtime, licences and native guides. Open SpeakTab.exe. Ctrl+O opens music; F2 finds music. Supported import routes include Guitar Pro, MusicXML, MuseScore, PDF, text tablature and chord charts, with format-specific limitations described in the manual.

Ctrl+1 focuses the music source or score summary. Ctrl+2 focuses score navigation. Left and Right move through time; Up and Down inspect simultaneous notes or strings. Ctrl+G jumps to a measure. F3 opens full beat details; Ctrl+3 opens the selected explanation style. Alt+Shift+F toggles compact string-fret pairs. Ctrl+P plays; Ctrl+Shift+P stops. Ctrl+Shift+0 clears a loop; Ctrl+S saves the reading.

## Guides and verification

The current full manual, two-page Quick Start, text and HTML editions, keyboard reference and embedded help cover version 50. Complete app and source packages are supplied in the numbered local delivery folders. Use the complete source handoff for development. Build.ps1 compiles and runs checks.

The root release gate and all 81 focused checks passed. The user reported that version 50 worked in local testing. The occasional empty staff label remains a minor known issue. Software checks do not certify every score, device or external service. Named ornaments are described without automatically expanding them into performed notes. Complex repeats and PDF recognition have documented limits. Main local reading and practice features do not require paid AI; optional connected AI requires its own working access.

The podcast rehearsal guide is titled SpeakTab Podcast Tutorial and Command Reminder 10.14.50. It provides nine free demonstrations and one optional AI demonstration.

Future vocal-score and wider instrument support, and the possible SpeakScore name, are planning items rather than current universal-support claims.
